# ERC-721 NFT Smart Contract

A secure and gas-optimized Non-Fungible Token (NFT) smart contract implemented using OpenZeppelin standards. This contract allows the owner to mint new unique tokens securely.

## Features
- **ERC-721 Standard:** Fully compliant with standard NFT interfaces and metadata handling.
- **Ownable Access Control:** Restricts the minting functionality so that only the contract owner can create new tokens.
- **Auto-Increment Token IDs:** Automatically tracks and assigns unique IDs for every newly minted NFT.

## Technologies Used
- Solidity (^0.8.20)
- OpenZeppelin Contracts
- Remix IDE / Hardhat
